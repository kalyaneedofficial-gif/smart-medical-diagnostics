# Smart Medical Diagnostics & Disease Prediction System

## Overview
An interactive Machine Learning system designed to provide preliminary diagnostic risk assessments using patient clinical data. Built with Python, Streamlit, and Scikit-Learn.

## Features
- Interactive input forms with real-time data validation.
- Multi-model diagnostic engine with high classification accuracy.
- Feature importance visualization and patient report generation.

## Technologies Used
- **Language**: Python 3.10+
- **Machine Learning**: Scikit-Learn, Pandas, NumPy
- **Interface**: Streamlit / Flask
- **Testing & Tooling**: Pytest, Git
